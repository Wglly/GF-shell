# Languages / 語言 / 语言 / 言語

Chinese, Simplified Chinese, English and Japanese** (`language` in `config.json`, or Settings → System →
Language for live switching).

## Conventions · 慣例

- The un-suffixed file (e.g. `README.md`, `docs/INSTALL.md`) is **Traditional Chinese**, the project's
  default language.
- Other languages use a BCP 47-style suffix: `README.zh-CN.md`, `README.en.md`, `README.ja.md`.
- Code blocks, commands, paths, config keys and screenshots are identical across languages — only prose
  is translated.
- Every translated file starts with a language bar linking to its siblings; keep those links and this
  table in sync when adding a language.

## Adding a language · 新增語言

1. Copy the English file and translate it: `README.<tag>.md`, `docs/INSTALL.<tag>.md`,
   `docs/CONFIG.<tag>.md`, `docs/ARCHITECTURE.<tag>.md`.
2. Update the language bar at the top of **all** existing versions (including the new one).
3. Add a column to the table above.
4. If the in-app UI should follow, extend the `dict` in `services/I18n.qml` and the `language`
   handling there — the docs alone do not change the shell's UI language.
