# 设计说明（少女前线 UI 语言）

[繁體中文](DESIGN.md) · **简体中文** · [English](DESIGN.en.md)

这份文档记录 GF-shell 的视觉决策、参考来源，以及「哪些是原创、哪些不能打包」。

## 参考来源

- [少女前线官方网站](https://gf.sunborngame.com/)：品牌色（暖炭黑、哑光金、钢蓝、警戒红）、窄体全大写标题、金色细线与斜切构图。
- [少前百科 GFwiki](https://www.gfwiki.org/)：游戏内界面截图（编成 / 基地 / 作战地图）——用来确认实际的信息密度、标签缎带、页签形状与字体比例。
- [爱给网「少女前线 UI」素材集](https://www.aigei.com/set/shaonvqianxian_ui.html)：仅作为「可购买素材的风格索引」参考；本项目**没有**下载或使用其中任何素材。

> 以上网站与游戏美术的著作权属于原权利人（Sunborn / MICA Team 等）。
> 本项目只借用「风格语言」，所有实际图形均由 `scripts/gen_assets.py` 或 QML 重新绘制。

## 从参考中提取的规则

1. **底色**：暖炭黑（`#141416` / `#070708`），不是冷蓝黑；让金色与纸白文字更突出。
2. **主强调色**：哑光金 `#e8bd4f`；选中态是「整块金色 + 黑字」，而不是只描边。
3. **副强调色**：钢蓝 `#6f9bc4`（基地 / 数据），**红色** `#d34a34` 只用于战斗力、警戒与危险操作。
4. **框线**：1px 金线 + 内侧 4px 处再一条细白线（双层框）；切角只在部分角落（右上 / 左下）。
5. **标签**：斜切平行四边形缎带（`GfTab` / `GfRibbon`），左侧色块放编号或图标，白字。
6. **排版**：标题用窄体全大写 + 大字距；数据用等宽；中文副题小、字距大、低对比。
7. **质感**：半调网点、等高线、等距基地线稿、细金线框、颗粒；**不使用** CRT 扫描线。
8. **版面**：信息密度高、对齐严格；面板彼此以金线分隔，而不是圆角卡片或阴影。
9. **设置界面刻意反相**：纸白底 + 黑色线条/黑带、黑灰按钮，悬停或选中时变黄——像少前的系统表单，而不是给深色面板换个颜色。

## 对应到组件

| 少前元素 | GF-shell 实现 |
| --- | --- |
| 选中页签（金底黑字、斜切） | `GfTab`（状态栏工作区、启动器分类） |
| 选中按钮 / 模块开关 | `GfButton`、`CcToggle`、`GfIconButton` 的 `checked` 态 |
| 斜切标签缎带 | `GfRibbon`（可带向下指示三角） |
| 双层面板框 | `GfFrame`（`borderColor` + `innerLine` + 小切角） |
| 标题带 | `GfSectionHeader`（金色方块 + 窄体白字 + 金线） |
| 资源 / 状态条 | `GfMeter`、`GfSlider`（金色分段 / 菱形指针） |
| 立绘框 | 启动器右侧档案（斜切金角 + 斜纹底） |
| 战斗力红字 | 启动器档案的 `COMBAT POWER` |

## 壁纸

默认壁纸是**原创**程序化构图：暖炭渐变、金色斜带、半调网点、等高线、等距基地线稿、
徽章水印、金色细框与数据条；四张变体（ops / sangvis / neural / dusk）共用同一套构图语言。
重新生成：

```bash
python3 scripts/gen_assets.py
```

### 使用官方公式图 / 游戏原画

本项目**不打包**任何官方美术（壁纸、立绘、Logo、UI 贴图）。如果你合法持有这些图片，
可以把它们放在本机并指定给外壳，程序不会复制或散布它们：

```json
// ~/.config/gf-shell/config.json
"wallpaper": {
  "enabled": true,
  "path": "file:///home/you/Pictures/gfl-wallpaper.png",
  "fillMode": "fill",
  "dim": 0.12
}
```

或在「副官设置 → 壁纸」直接选择文件路径。`dim` 建议 0.1–0.25，让黑色 UI 仍然清楚。

## 不能做的事（授权）

- 不从爱给网 / 游戏包 / 官方网站下载素材后放进 repo。
- 不重新散布 G&K / 铁血 / 游戏 Logo 的矢量或位图重绘（即使自己描的，也可能是衍生作品）。
- 徽章是原创设计（六角框 + 三层翼形雪佛龙 + 指挥星），不是任何官方标志。
