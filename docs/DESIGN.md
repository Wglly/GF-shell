# 設計說明（少女前線 UI 語言）

**繁體中文** · [简体中文](DESIGN.zh-CN.md) · [English](DESIGN.en.md) · [日本語](DESIGN.ja.md)

這份文件記錄 GF-shell 的視覺決策、參考來源，以及「哪些是原創、哪些不能打包」。

## 參考來源

- [少女前線官方網站](https://gf.sunborngame.com/)：品牌色（暖炭黑、啞光金、鋼藍、警戒紅）、窄體全大寫標題、金色細線與斜切構圖。
- [少前百科 GFwiki](https://www.gfwiki.org/)：遊戲內介面截圖（編成 / 基地 / 作戰地圖）——用來確認實際的資訊密度、標籤緞帶、頁籤形狀與字體比例。
- [愛給網「少女前線 UI」素材集](https://www.aigei.com/set/shaonvqianxian_ui.html)：僅作為「可購買素材的風格索引」參考；本專案**沒有**下載或使用其中任何素材。

> 以上網站與遊戲美術的著作權屬於原權利人（Sunborn / MICA Team 等）。
> 本專案只借用「風格語言」，所有實際圖形均由 `scripts/gen_assets.py` 或 QML 重新繪製。

## 從參考中提取的規則

1. **底色**：暖炭黑（`#242421` / `#151513`），不是冷藍黑；讓金色與紙白文字更突出。
2. **主強調色**：啞光金 `#d8aa4b`；選中態是「整塊金色 + 黑字」，而不是只描邊。
3. **副強調色**：鋼藍 `#87a0b2`（基地 / 數據），**紅色** `#c6523c` 只用於戰鬥力、警戒與危險操作。
4. **框線**：1px 金線 + 內側 4px 處再一條細白線（雙層框）；切角只在部分角落（右上 / 左下）。
5. **標籤**：斜切平行四邊形緞帶（`GfTab` / `GfRibbon`），左側色塊放編號或圖示，白字。
6. **排版**：標題用窄體全大寫 + 大字距；資料用等寬；中文副題小、字距大、低對比。
7. **質感**：半調網點（halftone）、等高線、等距基地線稿、細金線框、顆粒；**不使用** CRT 掃描線（少前沒有）。
8. **版面**：資訊密度高、對齊嚴格；面板彼此以金線分隔，而不是圓角卡片或陰影。
9. **設定介面刻意反相**：紙白底 + 黑色線條/黑帶、黑灰按鈕，滑過或選中時轉為黃色——像少前的系統表單，而不是把深色面板換個顏色。

## 對應到元件

| 少前元素 | GF-shell 實作 |
| --- | --- |
| 選中頁籤（金底黑字、斜切） | `GfTab`（狀態列工作區、啟動器分類） |
| 選中按鈕 / 模組開關 | `GfButton`、`CcToggle`、`GfIconButton` 的 `checked` 態 |
| 斜切標籤緞帶 | `GfRibbon`（可帶向下指示三角） |
| 雙層面板框 | `GfFrame`（`borderColor` + `innerLine` + 小切角） |
| 標題帶 | `GfSectionHeader`（金色方塊 + 窄體白字 + 金線） |
| 資源 / 狀態條 | `GfMeter`、`GfSlider`（金色分段 / 菱形指針） |
| 立繪框 | 啟動器右側檔案（斜切金角 + 斜紋底） |
| 戰鬥力紅字 | 啟動器檔案的 `COMBAT POWER` |

## 壁紙

預設壁紙是**原創**的程序化構圖：暖炭漸層、金色斜帶、半調網點、等高線、等距基地線稿、
徽章水印、金色細框與資料條；四張變體（ops / sangvis / neural / dusk）共用同一套構圖語言。
重新生成：

```bash
python3 scripts/gen_assets.py
```

### 使用官方公式圖 / 遊戲原畫

本專案**不打包**任何官方美術（桌布、立繪、Logo、UI 貼圖）。如果你合法持有這些圖片，
可以把它們放在本機並指定給外殼，程式不會複製或散布它們：

```json
// ~/.config/gf-shell/config.json
"wallpaper": {
  "enabled": true,
  "path": "file:///home/you/Pictures/gfl-wallpaper.png",
  "fillMode": "fill",
  "dim": 0.12
}
```

或在「副官設置 → 壁紙」直接選擇檔案路徑。`dim` 建議 0.1–0.25，讓黑色 UI 仍然清楚。

## 不能做的事（授權）

- 不從愛給網 / 遊戲包 / 官方網站下載素材後放進 repo。
- 不重新散布 G&K / 鐵血 / 遊戲 Logo 的向量或點陣重繪（即使自己描的，也可能是衍生作品）。
- 徽章是原創設計（六角框 + 三層翼形雪佛龍 + 指揮星），不是任何官方標誌。
