# デザインノート（『少女前線』UI の言語）

[繁體中文](DESIGN.md) · [简体中文](DESIGN.zh-CN.md) · [English](DESIGN.en.md) · **日本語**

このドキュメントは GF-shell の視覚的な判断、参考にしたもの、そして「何がオリジナルで、何を
同梱できないか」を記録したものです。

## 参考

- [『少女前線』公式サイト](https://gf.sunborngame.com/)：ブランドカラー（ウォームチャコール、
  マットゴールド、スチールブルー、警戒の赤）、コンデンス体の全大文字見出し、金の細線と斜めの構図。
- [GFwiki](https://www.gfwiki.org/)：ゲーム内 UI のスクリーンショット（編成／基地／作戦マップ）。
  実際の情報密度、ラベルリボン、タブの形、書体の比率を確認するために使用。
- [愛給網「少女前線 UI」素材集](https://www.aigei.com/set/shaonvqianxian_ui.html)：有料素材の
  スタイル索引としてのみ参照。**一切ダウンロード・使用していません**。

> これらのサイトとゲーム美術の著作権は権利者（Sunborn / MICA Team など）に帰属します。
> 本プロジェクトは「スタイルの言語」だけを借り、実際の図形はすべて
> `scripts/gen_assets.py` または QML で描き直しています。

## 参考から抽出したルール

1. **ベース**：冷たいブルーブラックではなく**暖かいチャコール**（`#242421` / `#151513`）。
   金と紙白の文字が引き立ちます。
2. **メインアクセント**：マットゴールド `#d8aa4b`。選択状態は「金色で塗りつぶし＋黒文字」で、
   枠線だけではありません。
3. **サブアクセント**：スチールブルー `#87a0b2`（基地／データ）。**赤** `#c6523c` は戦闘力、
   警告、危険操作だけに使用。
4. **枠**：1px の金線＋4px 内側にもう一本細い白線（二重枠）。面取りは一部の角だけ（右上／左下）。
5. **ラベル**：斜めの平行四辺形リボン（`GfTab` / `GfRibbon`）。左の色ブロックに番号やアイコン、
   白文字。
6. **タイポグラフィ**：見出しはコンデンス体の全大文字＋広い字間。データは等幅。中国語の副題は
   小さく、字間を広く、低コントラスト。
7. **質感**：ハーフトーンドット、等高線、アイソメトリックの基地線画、細い金枠、グレイン。
   CRT のスキャンラインは**使いません**（ゲームに無いため）。
8. **レイアウト**：情報密度が高く、厳密に整列。角丸カードや影ではなく、金の罫線で区切ります。
9. **設定画面は意図的に反転**：紙白の背景＋黒い罫線／黒帯、チャコールのボタン。ホバーや選択で黄色に変わります。ダークパネルの色違いではなく「システムの用紙」です。

## コンポーネントへの対応

| 少女前線の要素 | GF-shell の実装 |
| --- | --- |
| 選択タブ（金塗り＋黒文字＋斜め） | `GfTab`（ステータスバーのワークスペース、ランチャーの分類） |
| 選択ボタン／モジュールスイッチ | `GfButton`、`CcToggle`、`GfIconButton` の `checked` 状態 |
| 斜めのラベルリボン | `GfRibbon`（下向きの指示三角形つき） |
| 二重パネル枠 | `GfFrame`（`borderColor` + `innerLine` + 小さな面取り） |
| タイトル帯 | `GfSectionHeader`（金のブロック＋コンデンス体の白文字＋金線） |
| リソース／ステータスバー | `GfMeter`、`GfSlider`（金のセグメント／菱形ノブ） |
| 立ち絵枠 | ランチャー右側のファイル（斜めの金角＋ハッチ背景） |
| 赤い戦闘力の数字 | ランチャーの `COMBAT POWER` |

## 壁紙

既定の壁紙は**オリジナル**のプログラム生成です：暖かいチャコールのグラデーション、金の斜め帯、
ハーフトーンドット、等高線、アイソメトリックの基地線画、エンブレムの透かし、細い金枠とデータ帯。
4 つのバリエーション（ops / sangvis / neural / dusk）は同じ視覚文法を共有します。再生成：

```bash
python3 scripts/gen_assets.py
```

### 公式の告知画像／ゲーム原画を使う場合

本プロジェクトは公式美術（壁紙、立ち絵、ロゴ、UI テクスチャ）を**同梱しません**。合法的に所持して
いる画像は、ローカルに置いてパスを指定してください。プログラムがコピーや再配布をすることは
ありません：

```json
// ~/.config/gf-shell/config.json
"wallpaper": {
  "enabled": true,
  "path": "file:///home/you/Pictures/gfl-wallpaper.png",
  "fillMode": "fill",
  "dim": 0.12
}
```

または「副官設定 → 壁紙」からファイルを選択します。`dim` は 0.1–0.25 を推奨（黒い UI が読みやすい）。

## 行わないこと（ライセンス）

- 愛給網／ゲームパッケージ／公式サイトから素材をダウンロードしてリポジトリに入れること。
- G&K／サングヴィス／ゲームロゴのベクター・ラスターの再配布（自分で描き直しても派生作品になり得ます）。
- 同梱のエンブレムはオリジナルデザイン（六角形の枠＋三段の翼形シェブロン＋コマンドスター）で、
  公式のマークではありません。
